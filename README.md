# Equipo_Ternurin
**MercaDito Libre - Plataforma de Comercio Estudiantil UACJ**
Este repositorio contiene la propuesta de desarrollo, documentación técnica y planificación del sistema MercaDito Libre, diseñado para optimizar el comercio informal dentro de los institutos de la Universidad Autónoma de Ciudad Juárez


**Instrucciones para Colaboradores**
Clonar el repositorio.

Crear una rama siguiendo la nomenclatura **feat/nombre-de-la-tarea.**

Realizar los cambios y subir el Pull Request para revisión del equipo.

No realizar cambios directamente en la **rama main.**
